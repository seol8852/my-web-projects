## 🛠️ GitHub Pages 배포 가이드
1. 이 리포지토리의 `Settings` > `Pages` 메뉴로 이동합니다.
2. **Branch**를 `main` (또는 `master`), 폴더를 `/(root)`로 선택하고 **Save**를 누릅니다.
3. 1~2분 후 나오는 공식 웹 주소(`https://<아이디>.github.io/<저장소이름>/`)로 접속하시면 메인 허브와 모든 사이트가 활성화됩니다!
