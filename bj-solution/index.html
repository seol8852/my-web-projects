이름/전화번호 등을 비우고 '등록' 클릭 시 반드시 경고창(alert())이 뜨고 해당 입력창으로 커서(focus())가 이동해야 합니다. 누락 시 5~10점 감점!

3. 등급/코드 한글 명칭 변환

DB에 저장된 고객등급 'A', 'B', 'C'를 화면에 그대로 영문으로 출력하면 감점입니다. 'VIP', '일반', '직원'으로 한글 변환 분기 처리(if-else)를 해야 합니다.

4. 매출 집계 통계 쿼리 정렬

매출 통계 화면에서는 회원별로 구매 금액 합계(SUM(price))를 구하고, 반드시 매출이 높은 순서(ORDER BY total_price DESC)로 내림차순 정렬해야 완벽한 만점을 받습니다.

5. 리소스 누수 방지(Connection close)

DAO 메서드마다 finally 블록에서 rs.close(), pstmt.close(), conn.close()를 안전하게 닫아야 WAS 메모리 고갈 오류를 방지할 수 있습니다.

STEP 1 · 환경변수

📌 JDK 'PATH' & 'JAVA_HOME' 환경변수 완벽 세팅

⚙️

이클립스와 톰캣이 운영체제에서 올바른 자바 컴파일러(javac)를 찾으려면 JAVA_HOME 시스템 변수와 Path 등록이 필수입니다.

📝 윈도우 GUI 설정 순서:
  1. Win + R ➡️ sysdm.cpl 입력 후 엔터 ➡️ [고급] 탭 ➡️ [환경 변수(N)...] 클릭
  2. [시스템 변수] 아래 [새로 만들기] 클릭:
    변수 이름: JAVA_HOME
    변수 값: C:\Program Files\Java\jdk-17 (또는 jdk1.8.0_xxx 등 설치 폴더)
  3. [시스템 변수] 목록에서 Path를 찾아 [편집] 클릭 ➡️ [새로 만들기] 클릭:
    %JAVA_HOME%\bin 추가 후 [위로 이동]하여 최상단 쪽으로 배치
  4. 열려있는 모든 창에서 [확인]을 눌러 적용 완료.
💻 CMD 검증 명령어 (복사하여 명령 프롬프트에 붙여넣기): 
:: 1. JAVA_HOME 변수 정상 등록 확인 (경로가 출력되어야 함)
echo %JAVA_HOME%

:: 2. 자바 런타임 버전 확인
java -version

:: 3. 자바 컴파일러 정상 인식 확인 ('내부 또는 외부 명령어가 아닙니다' 뜨면 Path 오류!)
javac -version
🚨 'javac'은(는) 내부 또는 외부 명령이 아닙니다 에러 발생 시:

JRE가 아닌 JDK가 설치되어 있는지 확인하고, %JAVA_HOME%\bin 경로 안에 javac.exe 파일이 실제로 존재하는지 탐색기로 직접 확인하세요. 명령 프롬프트(CMD) 창을 새로 띄워야 환경변수가 반영됩니다!

STEP 2 · 데이터베이스 PASS 설정

🔐 MySQL root 비밀번호(PASS) & 인증 플러그인 변경

🔑

시험장에서는 root 계정의 비밀번호를 단순하게(예: 1234) 통일하고, MySQL 8.0의 까다로운 인증 암호화(caching_sha2_password)를 전통적인 mysql_native_password로 전환해야 JDBC 연동 에러가 100% 예방됩니다.

💻 MySQL 콘솔에서 실행할 비밀번호(PASS) 변경 SQL: 
-- 1. root 계정 비밀번호를 '1234'로 변경하고 native password 인증 플러그인으로 변경
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '1234';

-- 2. 변경된 권한 즉시 메모리에 반영
FLUSH PRIVILEGES;

-- 3. 변경 결과 확인 (plugin이 mysql_native_password 로 되어 있는지 확인)
SELECT user, host, plugin FROM mysql.user WHERE user = 'root';
💡 혹시 시험장에서 이전 수험자가 설정한 root 비밀번호를 모를 때 긴급 복구법:
  1. 윈도우 서비스(services.msc)에서 MySQL 서비스를 일시 [중지]합니다.
  2. 관리자 권한 CMD에서 mysqld --skip-grant-tables --shared-memory 실행 (인증 검사 건너뛰기).
  3. 새 CMD 창을 열고 mysql -u root 입력 (암호 없이 접속됨).
  4. FLUSH PRIVILEGES; 실행 후 위의 ALTER USER ... BY '1234'; 쿼리를 실행하여 비밀번호를 재설정합니다.

STEP 4 · WAS 설정

🚀 Tomcat 포트(8090) 변경 & Context Path 루트( / ) 지정

🌐

시험장에서 가장 흔한 0점 요인은 404 Not Found입니다. 포트 충돌을 피하고 브라우저에서 http://localhost:8080/index.jsp로 바로 열리도록 Context Path를 /로 변경해야 합니다.

🔌 1. 포트 충돌 방지 (8080 ➡️ 8090)
  1. 이클립스 하단 Servers 탭에서 Tomcat v8.5 / v10.1 Server를 더블클릭합니다.
  2. 열리는 설정 화면 우측 Ports 표에서 HTTP/1.1 포트를 확인합니다.
  3. 만약 오라클 충돌 등으로 에러가 나면 8080을 8090(또는 8088)으로 변경합니다.
  4. Ctrl + S를 눌러 저장합니다.
🎯 2. Context Path를 루트(/)로 변경 (404 완벽 방지)
  1. Tomcat 서버 설정 창 하단의 Modules 탭을 클릭합니다.
  2. 추가된 내 프로젝트(예: HRD_1234)를 클릭하고 우측 [Edit...] 버튼을 누릅니다.
  3. Path: 입력창에 적힌 /HRD_1234를 지우고 오직 슬래시 하나( / )만 남깁니다.
  4. [OK] ➡️ Ctrl + S로 저장하면 이제 http://localhost:8080/index.jsp로 즉시 접근됩니다!
STEP 5 · 라이브러리 배포

📦 JDBC Driver JAR 올바른 등록 (ClassNotFoundException 1초 해결)

📚

많은 수험생이 이클립스 [Build Path]에만 JAR를 등록했다가 톰캣 구동 시 ClassNotFoundException: com.mysql.cj.jdbc.Driver 에러를 맞닥뜨리고 당황합니다. 톰캣 웹앱은 반드시 WEB-INF/lib 안에 JAR가 물리적으로 복사되어 있어야 합니다!

📁 올바른 배치 경로 확인 (절대 법칙):
내 프로젝트 폴더
└── WebContent (또는 src/main/webapp)
    └── WEB-INF
        └── lib
            └── mysql-connector-j-8.0.33.jar (여기에 복사 & 붙여넣기!)
💡 팁: 윈도우 파일 탐색기에서 mysql-connector-j-8.x.jar 파일을 복사(Ctrl+C)한 후, 이클립스 패키지 탐색기의 WebContent/WEB-INF/lib 폴더를 누르고 붙여넣기(Ctrl+V)만 하면 별도의 복잡한 Build Path 추가 없이도 컴파일과 톰캣 배포가 동시에 해결됩니다.
시험장 긴급 처방

🚨 시험장 5대 치명적 런타임 에러 1분 처방전

시험 진행 중 화면이 하얗게 뜨거나 빨간 에러가 터졌을 때 즉시 확인하고 1분 안에 복구하는 핵심 솔루션입니다.

🚑

❌ 1. HTTP 404 Not Found

원인: 파일명 오타, 폴더 위치 오류, 이클립스 Context Path 불일치
해결: Tomcat 서버 더블클릭 ➡️ Modules 탭 ➡️ Path를 /로 변경하거나 WebContent 바로 아래 JSP 파일 위치 확인

⚠️ 2. HTTP 500 NullPointerException

원인: HTML 폼 name 속성과 request.getParameter("name") 철자 불일치
해결: 파라미터 철자 대소문자 일치 확인 및 Integer.parseInt() 전 null 체크

🔌 3. ClassNotFoundException: Driver

원인: JDBC jar 라이브러리가 톰캣 실제 배포 경로에 없음
해결: mysql-connector-j-8.x.jar를 WebContent/WEB-INF/lib 폴더 안에 복사-붙여넣기

🔑 4. Access denied for user 'root'

원인: DB 비밀번호 오타 또는 포트 3306 미실행
해결: DBConnection.java의 비밀번호(1234 등) 재확인 및 윈도우 서비스에서 MySQL 서비스 시작 확인

HTML 태그 / 속성실제 코드 예시시험장 역할 & 감점 방지 팁
<form> <form name="frm" method="post" action="action.jsp" onsubmit="return check();"> method="post"는 한글이나 많은 데이터를 안전하게 전송. onsubmit="return check()"에서 false 반환 시 전송 취소

submit vs button <input type="submit" value="등록">
<input type="button" value="조회" onclick="location.href='list.jsp'">		 등록 버튼은 submit으로 폼 이벤트 트리거, 조회/취소 버튼은 type="button"에 JS location.href 연결
<table> 격자 <table border="1" style="width: 100%; border-collapse: collapse; text-align: center;"> border-collapse: collapse는 테두리 2줄 겹침을 방지하여 깔끔한 단일 실선 표로 렌더링

👑 2. 100% 출제 복합 쿼리 공식

SELECT a.id, a.name,
       CASE a.grade WHEN 'A' THEN 'VIP' WHEN 'B' THEN '일반' ELSE '직원' END AS 등급,
       IFNULL(SUM(b.price), 0) AS 총매출
FROM tbl_a a
LEFT JOIN tbl_b b ON a.id = b.id
GROUP BY a.id, a.name, a.grade
ORDER BY 총매출 DESC, a.id ASC;

⚠️ SELECT에 쓴 일반 컬럼만 GROUP BY에 넣고 SUM은 제외!
