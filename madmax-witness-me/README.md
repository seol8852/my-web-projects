# 🔥 매드맥스 분노의 도로 - 기억해줘! (WITNESS ME!) HTTPS 웹사이트

영화 《매드맥스: 분노의 도로》의 명장면인 워보이의 **"기억해줘! (WITNESS ME!)"** 짤과 대사가 나오는 로컬 HTTPS 인터랙티브 웹사이트입니다.

## 🚀 친구에게 메일로 보낼 때 & 실행 방법

1. 이 `madmax-witness-me` 폴더 전체를 **ZIP 파일로 압축**하여 친구에게 메일로 전송합니다.
2. 친구는 받은 ZIP 파일의 **압축을 풉니다.**
3. 폴더 안에 있는 **`start.bat`** 파일을 **더블 클릭**합니다!
4. 브라우저가 열리며 `https://localhost:8443`으로 접속됩니다.
   - *💡 브라우저에 "연결이 비공개로 설정되어 있지 않습니다" 경고가 뜨면 `[고급]` -> `[localhost(으)로 이동(안전하지 않음)]`을 한 번만 클릭해주시면 됩니다.*

---

## ⚡ 주요 기능

- **🥫 크롬 락카 치이익! (Shiny & Chrome)**: 워보이의 입가에 크롬 은색 락카를 칠하고 은빛 분진 파티클 폭발!
- **💀 기억할게! (WITNESSED!)**: 발할라로 돌진하는 워보이들을 위한 화염 폭발 및 증인 카운트 증가!
- **🎸 두프 워리어 BGM**: Web Audio API 신시사이저로 연주되는 아포칼립스 헤비메탈 기타 리프
- **⚡ 명대사 릴레이**: 매드맥스의 대표 명대사 순환
- **🔒 제로 의존성(Zero-dependency) HTTPS**: Node.js 또는 Python 기본 내장 모듈만으로 완벽 구동
